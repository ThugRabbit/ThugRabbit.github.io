## First Blog with Hugo leaf bundle
### Overviews of Leaf bundle.
here is an example of it. 
Firstly hugo already has these bundle by default. And we dont need to install them one by one. There is only 2 bundles named Leaf bundle and Branch bundle. we can know them by the name easily, Leaf bundle means current node as a terminate node, and a branch node might have child nodes. Basically Leaf bundle could take as a blog, but with a special structure, while Branch bundle is a directory, includes a specific type of blogs (like knowledge, blog, daily ideas, notes, etc)
### Advantages of using bundle structure.
Files are more organized, you can simply include the picture in the format of "!\[$name\]\($picturename.img\)".
